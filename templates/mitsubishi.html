Mitsubishi Comfort Optional module

Comfort overview

Connect your Comfort account to add temperature, mode and heating/cooling setpoints. No temperatures, schedules or operating modes are changed. No adapter reboots are sent.

Cloud retrieval time is not a sensor measurement time. Adapter “connected” is a vendor-reported state, not proof of a fresh physical reading. Missing data stays unknown. This module does not measure HVAC watts.

Add / reconnect module

Your password is used for sign-in only and is not saved. Access and refresh tokens are stored in an owner-only file on the collector. Reconnecting replaces the connection only after successful discovery.

Removal deletes saved tokens, clears current cards and stops further requests from this module. Recorded history is retained. It does not delete or reset devices in Comfort.

Continuous collection requires the separate optional mitsubishi_collect.py service. If it is not running, snapshots become stale after three minutes.
